# Mascote CLAWD: cabeça-caixa fiel + corpo HUMANO, nunca fofo/robozinho

**O que aprendi:** O mascote do Claude Code do Flávio se chama CLAWD — arquivo oficial em `plugins/dna-operacional/lib/carrossel/mascote/clawd-oficial.jpeg`. É um robô coral de **cabeça-caixa achatada e larga, 2 olhos pretos verticais, sem boca**. As variações virais (refs que o Flávio mandou) mantêm a CABEÇA CLAWD fiel mas dão a ela um **corpo HUMANO pixelado robusto** + figurino temático: bodybuilder musculoso, super-herói (capa vermelha + "C" no peito), staff (chapéu+óculos+crachá+celular+café).

**Por quê:** Gerei 2 versões erradas — um robô voxel 3D, e um "robozinho 2D fofo" (cabeça-caixa + corpinho de robô). O Flávio: "muito infantilizado, não fez leitura das referências". O estilo certo é 2D pixel art **chamativo e meio edgy** (raios, poses fortes, figurino), não cartoon fofo. A chave é o CORPO HUMANO + adereço, não um boneco-robô.

**Como aplicar:**
- Gerar variações sempre com `gerar-imagem -i .../clawd-oficial.jpeg`, pedindo: corpo humano pixelado robusto/atlético + cabeça-caixa coral fiel (olhos verticais, sem boca) + figurino/adereço do tema. 2D flat 16-bit, NÃO 3D, NÃO fofo.
- CLAWD é a identidade visual recorrente da skill de carrossel (como o itstylergermain/noevarner usam o mascote deles). [[carrossel-ativos-reais]] [[carrossel-bg-foto-criador]]
- Para "viralizar no IG": CLAWD segurando celular com Instagram + corações/raios explodindo.
